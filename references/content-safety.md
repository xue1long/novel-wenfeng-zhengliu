# 来源与内容隔离

## 使用前

- 确认用户接受选定文本进入当前会话所用模型的上下文；不要求用户声明来源处理权。
- 默认把来源正文、留出集、来源地图、证据摘录、运行记录和评分原始数据保存在本 Skill 根目录的 `out/<run-id>/` 私有运行区。根目录 `.gitignore` 必须忽略 `/out/`；不得把这些内容复制到其他项目文件、生成 Skill 或发布包。
- `out/` 仅是本地工作区边界；Git 忽略不提供加密或操作系统访问控制。若用户需要更严格的本地访问隔离，应使用其指定的受保护目录。
- 不把本机 Skill 的安装方式描述成模型处理必然只在本机。任何辅助脚本都不得上传来源文件。

## 生成内容

Style Bundle 和写作 Skill 只保留抽象表达机制。不得包含：

- 原文句子、长摘录或可识别的改写；
- 原作人物、剧情、世界观、事件顺序或独创意象组合；
- 书名、作者名、来源路径或可从中推断身份的名称。

用户要求保留醒目原句、独创意象或来源特征时，简短说明会改为抽象机制，并继续完成安全的蒸馏结果。生成新场景时换用不同的人物、物件、场景与意象，不把原作元素换名后复用。

## 自动过滤和模型检查

- `content_exclusions` 默认留空。不得把书名、作者名、人物名或其他来源实体复制到生成产物的过滤名单；通过通用类别规则排除来源专名、剧情、人物和独创意象。
- 生成前由模型逐项核对机制卡、Bundle 和 Skill，删除原句、可识别改写、来源角色/剧情细节和独创意象组合；不需要用户审定机制或过滤名单。
- 精确禁用项检查只能发现明确字符串；当前没有经过校准的相似度阈值。不得声称模型自查或字面检查能提供语义级保证。报告中说明隔离检查的边界。
